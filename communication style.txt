Known Issues I Solved

Page going white after updates → Write directly to Firebase, not through setData()
"Cannot read properties of undefined" → Add safety checks: data.items && data.items.map(...)
Data not syncing → Use real-time listener, not .once()
Losing login on refresh → Save auth state to localStorage
Infinite loops → Remove auto-save useEffect, use direct Firebase writes

My Current Firebase Pattern
javascript// Loading data
useEffect(() => {
    const dataRef = database.ref('buildingData');
    
    const unsubscribe = dataRef.on('value', (snapshot) => {
        const firebaseData = snapshot.val();
        if (firebaseData) {
            setData(firebaseData);
            setIsLoading(false);
        } else {
            const defaultData = getDefaultData();
            dataRef.set(defaultData);
            setData(defaultData);
            setIsLoading(false);
        }
    });

    return () => dataRef.off('value', unsubscribe);
}, []);

// Updating data
const handleUpdate = (field, value) => {
    database.ref(`buildingData/${field}`).set(value);
    // DON'T call setData - listener handles it
};

## Error Messages I've Seen (For Reference)

### Solved Errors
1. `Cannot read properties of undefined (reading 'map')` 
   - **Fix:** Add safety checks before `.map()`

2. `TypeError: firebaseData.map is not a function`
   - **Fix:** Check if data structure matches what I expect

3. `Permission denied` in Firebase
   - **Fix:** Check security rules are `.read: true, .write: true`

4. Page goes white after clicking update
   - **Fix:** Don't use `setData()` in update functions, write to Firebase directly

5. Browser shows old version of code
   - **Fix:** Hard refresh (Ctrl+Shift+R) or clear cache
